# 历史的碎屑散落

按日期、地点、人物与时间区间探索全球历史的静态网页应用。

## 运行与发布

在本目录执行 `python -m http.server 8765`，访问 http://localhost:8765 。地图资源需通过 HTTP 加载。无需安装依赖或配置 API Key；解压地图需支持 DecompressionStream 的现代浏览器。GitHub Pages 使用 main 分支的根目录。

## 检索

- 精选事件：8 条记录、6 个地区；支持历史地名、现代名、人物、来源名称、年份与地区筛选，采用时间区间相交。
- 开放来源：中文维基百科、英文维基百科、Wikidata；每来源最多 5 条，保留原文链接与更新时间/实体编号。关键词发送至所选来源，年份和地区限制不适用于在线条目。
- 具体日期：读取中文维基百科日期条目的“大事记”，严格匹配事件年份；可查看不同年份的同月同日。支持闰年、取消旧请求、分页、超时及来源修订版本。不混入出生与逝世列表。

没有检索结果只代表当前来源未收录，不代表没有历史事件。

## 地图

Natural Earth 1:110m 真实海岸线，采用 D3 等距圆柱投影。事件与底图使用相同坐标投影，支持缩放和拖动。

32 个 Historical Basemaps 政权/文化区域快照，范围为公元前 3000 年—2010 年。具体日期与选中的精选事件可自动切换参考年份，也可手动选择年份或快照。**不做疆界插值**：检索年与实际数据年分别显示，相邻快照只供参考；超出覆盖范围仅显示自然地理底图。跨年查询或没有唯一年代的关键词结果不自动选定一幅历史疆界图。区域名称沿用数据集；数据中既有政权，也有文化区域。地图并非逐日、全球一致精度的历史复原。

历史聚落仅使用上游有数值居住始年的 70 条样本（since=0 不显示），按 since/until 筛选。缺少终年不证明持续居住；名称可能是现代名称，不能保证是当年城名。数据地区分布不均衡，非全量城市。

在线事件自动读取关联维基条目主坐标或 Wikidata P625，仅显示地球坐标，排除弃用声明。不将人物出生地猜测为事件地点。城市/地区坐标属于来源条目，不保证是事件精确发生地；同坐标聚合，点击可查看记录和坐标出处。切换检索会清除旧标点。

自然海岸线是现代形态，未重建古海岸、古河道、古城市街区或海平面变化。

## 历史数据与许可

负数表示公元前，无公元 0 年。约年检索包络不是统计置信区间，世纪级记录不推测精确日期；具体日期按来源记载，不自动转换公历/儒略历/农历或地方时区。“今天”按 Asia/Shanghai 计算。

精选事件依据博物馆、图书馆、档案馆和 UNESCO 资料人工摘要；维基来源为社区编辑资料，需核对脚注和争议。同时代人物为演示生卒区间相交，尚待补充逐条传记证据，不代表参与事件或相互认识。

详见 `geo/SOURCES.md`。Natural Earth 为公有领域；Historical Basemaps 的改编地理数据采用 GPL-3.0，完整条款在 `geo/HISTORICAL-LICENSE.txt`；D3 7.8.5 条款见 `vendor/D3-LICENSE.txt`。维基百科摘要为 CC BY-SA，作者/修订历史见原条目；Wikidata 结构化数据为 CC0。地图以 gzip 传输，解压后是可编辑 GeoJSON，数据源和本项目源文件均公开。
