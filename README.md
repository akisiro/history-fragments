# 历史的碎屑散落

以具体事件为中心的全球历史检索网页，静态托管在 GitHub Pages。

在此目录运行 `python -m http.server 8765`，访问 http://localhost:8765。无需服务端、API Key 或安装项目依赖。地图解压需要现代浏览器支持 DecompressionStream。

## 检索与事件介绍

默认同时检索中文维基百科、英文维基百科和 Wikidata，来源选项收起。明确事件显示时间、主要人物、地点、背景/原因、经过或影响及原文标签；字段从百科导言、信息框、背景章节与 Wikidata 属性提取，缺项不推测。本地有出处的资料作为检索补充，但不预先展示精选列表。人物搜索显示其明确参与或有来源关联的事件，人物与其他主题不作为事件存入历史片段。

模糊线索提供可选择的事件/人物入口，精确事件不再显示各来源的百科结果列表。来源之间不被当成独立史料的交叉验证。部分来源失败时保留可用资料和错误提示。

起止年份隐藏；默认截至检索发生时刻（Asia/Shanghai），不设置未经证实的“最早历史事件”精确年份。公元前与不确定年代保留来源粒度，无公元0年，不自动换算儒略历/公历。日期检索沿用维基日期条目“大事记”，不混入生日、忌日及节假日。

## 同时发生的世界

事件介绍中可查询同年（或事件持续年份）及前后五年的其他地点事件。查询 Wikidata 事件类别、发生/起始时间与地点，去重并排除相同地点；只比较来源可确认的地点，不填补未知位置，不暗示因果。长事件可能返回有限样本，非完整世界史。记录缺失或接口失败会明确提示。

## 历史片段

仅保存实际打开的事件，最多九条。重复打开置顶；第十个移除最早一条；可单独删除。数据保存在当前浏览器 localStorage，浏览器禁止存储时只保留本次会话。初始无查看记录，不用精选数据填充。

## 两个人物的联系

双人物姓名表单通过 Wikidata 中英姓名/别名与中文百科实体映射获取真实人物候选。核对身份后点击查看；同名不自动选第一条。

直接读取双向亲属、师生与思想影响等字段，保留关系方向、限定时间、原字段链接及可读参考资料。弃用声明不参与结果；附参考资料不代表已独立核验。共同人物路径只用两条直接关系，共同事件依据双方参与属性；百科共现单独标为线索，不能证明相识、合作或直接关系。

来源连接失败与无记录分别提示，不判定两人没有联系。已有事件按输入姓名提供离线补充，并提示同名核对。查询人物关系本身不加入九条历史片段，只有打开具体事件才记录。

此版本尚未调用 AI。资料不足时保留证据缺口，不用模型补写史实。后续启用 AI 需要单独配置服务端和安全凭据，并区分有来源的事实与待核实解释。

## 地图

所有年代保留原来的可缩放、可拖动交互地图，不使用用户上传的地图图片。Natural Earth 1:110m 海岸线采用 D3 等距圆柱投影；事件标点与地图使用同一坐标投影。

32个 Historical Basemaps 政权/文化区域快照覆盖公元前3000年—2010年，按最近年份匹配并明确标注差距，不做疆界插值。无唯一年代或超出范围仅显示自然地理底图；不冒充检索当天的准确疆界。历史聚落为70个有居住年代记录的样本，非全量城市。现代自然海岸线未复原古河道、海岸或城市街区。
