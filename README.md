# 历史的碎屑散落

一个无需安装依赖的全球历史检索网页原型，可部署至 GitHub Pages。

## 运行

直接打开 `index.html` 即可使用，或在本目录执行 `python -m http.server 8765`，访问 http://localhost:8765 。

## 首版范围

- 8 条精选事件，覆盖 6 个地区；不代表完整的全球历史。
- 按事件、人物、历史地名、现代地名及部分英文别名检索；支持地区与年份组合筛选。
- 地图、按真实年份比例排列的时间轴、卡片和详情联动。
- 事件详情包含机构资料链接、来源类别、年代解释和地点角色。
- 同时代人物使用演示人物库的生卒区间相交算法；不意味着发生直接联系。生卒数据待补逐条传记证据。

## 历史数据规则

`data.js` 中每条事件保留 `start/end`、原始显示年代 `date`、精度 `precision`、历史名 `place`、现代对应 `modern`、别名 `aliases`、近似经纬度、相关人物、来源和解释说明。

负数代表公元前，无公元 0 年。时间筛选使用闭区间相交；日级记录在筛选时按年处理。约年采用显式检索包络，不表示真实误差概率。宽泛世纪记录采用整个世纪范围，不推测精确年份。

地图为项目自行绘制的概略海岸线，仅表达空间关系；不含国界、历史疆域或导航精度。敦煌记录标记出土地，奋进号标记航程代表点，不冒充生产地点或完整路线。

事件来源采用博物馆、图书馆、档案馆与 UNESCO 机构材料，原始链接随记录保留。摘要为人工改写，并非原文引用。资料整理于 2026-10-16；正式数据库仍需双来源复核、字段级证据、异说记录和编辑审核。

## 验证

使用 Node.js 运行 `node test.cjs`，验证公元前年份、区间相交、约年检索包络、别名、人物检索、地区筛选及空结果。

## 发布到 GitHub Pages

建议公开仓库地址名：`history-fragments`；仓库描述及网页名称：历史的碎屑散落。

将此目录全部文件上传到公开仓库，在 Settings → Pages → Build and deployment 选择 Deploy from a branch，然后选择 main 分支与 / (root)，保存。发布地址由 GitHub Pages 返回。

本项目不依赖后台、第三方地图请求、API Key 或构建步骤。所有网页资源均使用相对路径，可用于仓库子路径。
